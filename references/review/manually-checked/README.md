# Manually checked reviews

Reserved for records that pass the `MANUALLY_CHECKED` admission criteria.
Manual checking is not scholarly verification.

The nine Stage 3C records were produced by an AI visual transcription
assistant performing manual scan comparison. The reviewer role and decision in
each record explicitly state that the check is not qualified Shafi‘i scholarly
review. These records remain non-executable, have no approved cases, and have
no implementation specification.
